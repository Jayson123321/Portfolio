# Hoe ik op dit pad ben gekomen: Van Mavo en ICT-Beheer naar AI
Mijn reis in de technologiewereld begon op de mavo, waarna ik de opleiding IT Systems and Devices (ICT-beheer) ben gaan volgen aan het ROC van Amsterdam (ROCvA) Zuidoost. Tijdens deze opleiding maakte ik diepgaand kennis met IT-infrastructuur en security. 

Tijdens mijn mbo-opleiding liep ik stage bij Allinq, waar ik op Schiphol aan de slag ging als ICT Field Engineer stagiair. Dit was een unieke en verantwoordelijke werkomgeving. Ik werkte in datacenters en technische ruimtes, waar ik onder andere patchkasten inrichtte, netwerk-werkruimtes realiseerde en verantwoordelijk was voor het trekken van kabels en het nauwkeurig aanleggen van glasvezelverbindingen. Daarnaast behaalde ik waardevolle certificaten, waaronder Microsoft Office Specialist (MOS), Cisco Cybersecurity Essentials en Cisco CCNA Introduction to Networks.

Hoewel de focus hier op de fysieke en beheerkant van netwerken lag, wist ik na het afronden van de opleiding dat ik een andere richting op wilde: ik wilde zelf applicaties leren bouwen en software-oplossingen creëren. Die drang om te programmeren heeft mij geleid naar de specialisatie in Software Development, wat uiteindelijk de perfecte springplank bleek te zijn naar AI Engineering.

# Git Projecten en Portfolio
Hieronder staat een overzicht van de belangrijkste repositories en geavanceerde software- en AI-oplossingen die ik heb ontworpen en gebouwd:

## Project 1: Juf Aimee (HBO Leerjaar 3 - AI & RAG Oplossing)
Voor het hoogbegaafd onderwijs heb ik samen met drie teamleden een doordachte AI-assistent gebouwd die leerkrachten ondersteunt. Ik heb voor dit project zelf de architectuur bedacht en de RAG-oplossing (Retrieval-Augmented Generation) ontworpen en gebouwd. Complexe data van hoogbegaafde kinderen (zoals TIQ, zwakheden, specifieke behoeftes en interesses) heb ik omgezet naar vectors en opgeslagen in een vector database. Daarnaast heb ik een MCP-server (Model Context Protocol) geïntegreerd, waardoor externe databronnen naadloos verbonden konden worden met de AI. Dit is een project waar ik enorm trots op ben vanwege de diepgaande AI-architectuur.

## Project 2: Dutch Elections Results Visualization (HBO Leerjaar 2)
Een full-stack webapplicatie ontwikkeld aan de Hogeschool van Amsterdam (HvA) om de resultaten van de Nederlandse Tweede Kamerverkiezingen van 2023 te visualiseren. De applicatie bevat functies zoals data-visualisaties, partijfilters en sorteeropties met een volledig responsive design voor desktop en mobiel.
* **Mijn Rol:** Verantwoordelijk voor het verwerken van de XML-dataset naar de database met Java, het ontwerpen en configureren van de frontend, het UX/UI design en de volledige Docker-deployment op een Render-server.
* **Tech Stack:** Java (Spring Boot), Vue.js, JavaScript, Chart.js, HTML, CSS en Docker.

## Project 3: Mijn Portfolio AI-Assistent (Huidig Project)
Dit project is de AI-assistent die je nu op mijn portfolio-website gebruikt. Het is een ethische RAG-chatbot gebouwd volgens de principes van Responsible AI. De assistent maakt gebruik van de Google Gemini API (`text-embedding-004`) en een vector database om op een veilige, transparante en nauwkeurige manier vragen van bezoekers over mijn achtergrond, projecten en vaardigheden te beantwoorden zonder te hallucineren.
